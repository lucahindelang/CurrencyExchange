Fetching Data from API

  • Calculating Start Date
start_date_list = str(datetime.now() - timedelta(weeks = backdating_weeks))
start_date = start_date_list.split(" ")[0]
  • API
url_eur_chf = f"https://api.frankfurter.dev/v2/rates?base={currencies["eur"]}&from={start_date}&quotes={currencies["chf"]}"
url_eur_usd = f"https://api.frankfurter.dev/v2/rates?base={currencies["eur"]}&from={start_date}&quotes={currencies["usd"]}"
url_eur_gbp = f"https://api.frankfurter.dev/v2/rates?base={currencies["eur"]}&from={start_date}&quotes={currencies["gbp"]}"
url_eur_jpy = f"https://api.frankfurter.dev/v2/rates?base={currencies["eur"]}&from={start_date}&quotes={currencies["jpy"]}"
  • Overview Of Fetched Data

The response from the API is a list of JSON-Objects.
Applying the json() method on the response you can convert the list of JSON-Objects into a list of dictionaries.

response_eur_chf = requests.get(url_eur_chf)
response_eur_usd = requests.get(url_eur_usd)
response_eur_gbp = requests.get(url_eur_gbp)
response_eur_jpy = requests.get(url_eur_jpy)

data_eur_chf = response_eur_chf.json()
data_eur_usd = response_eur_usd.json()
data_eur_gbp = response_eur_gbp.json()
data_eur_jpy = response_eur_jpy.json()

print(data_eur_chf[0])
print(data_eur_usd[0])
print(data_eur_gbp[0])
print(data_eur_jpy[0])

Plot Charts

  • EUR <-> CHF - Exchange Rate
fig_eur_chf = px.line(df_eur_chf, 
                x = "date", y = [df_eur_chf["rate"], 1/df_eur_chf["rate"]],
                title = f"{currencies["eur"]} <-> {currencies["chf"]} - Exchange Rate", 
                labels = {"date": "Date", "value": "Exchange Rate"}, 
                height = 400, width = 800
                )
fig_eur_chf.data[0].name = f"{currencies["eur"]} / {currencies["chf"]}"
fig_eur_chf.data[1].name = f"{currencies["chf"]} / {currencies["eur"]}"
fig_eur_chf.show()
  • Summary

The chart shows the EUR/CHF exchange rate together with its inverse CHF/EUR over the last 52 weeks.

  • EUR/CHF (blue) trends slightly downward overall (from about 0.94 to 0.916), meaning 1 EUR buys fewer CHF than at the start of the period.
  • CHF/EUR (red, inverse) trends upward accordingly (from about 1.066 to 1.092), meaning 1 CHF buys more EUR over time.
  • The movement is relatively smooth with short-term fluctuations, but the broader pattern suggests a gradual strengthening of CHF against EUR during the observed period.
